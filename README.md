# Design System SaaS Landing Page (Community)

This is a code bundle for Design System SaaS Landing Page (Community). The original project is available at https://www.figma.com/design/3B3oZw4ZOiyg60TxblZaNz/Design-System-SaaS-Landing-Page--Community-.

## Running the code

1. Run `npm i` to install dependencies.
2. Run `npm run dev` to start the Vite development server.
3. Open the URL printed by Vite (usually `http://localhost:3000`).

> **Important:** Do not open `index.html` directly (or serve the repo root with a generic static server).
> This app uses a TypeScript/TSX entry module (`/src/main.tsx`), which must be transformed by Vite. If you skip Vite,
> browsers may fail with: `Expected a JavaScript-or-Wasm module script ... MIME type of "binary/octet-stream"`.

## Production preview

- Build the app: `npm run build`
- Preview the built app: `npm run preview`
